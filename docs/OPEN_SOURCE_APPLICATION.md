# Codex For Open Source Application Notes

Use this page as a concise reference when applying to OpenAI's Codex for Open Source program.

## Repository

https://github.com/tomphere/ontology-agent

## Maintainer Role

Primary maintainer responsible for architecture, releases, documentation, issue triage, security cleanup, and ongoing maintenance.

## Why This Repository Qualifies

Ontology Agent is a new open-source infrastructure project for ontology-driven knowledge graphs and LLM agents. It combines FastAPI, React, Neo4j, RDF/OWL parsing, relational-to-graph mapping, CDC sync, and natural-language graph QA. It targets a practical gap between semantic-web tooling, graph synchronization, and LLM agent workflows.

## API Credits Usage

API credits would support maintainer workflows: automated PR/code review, issue triage, release notes, documentation generation, prompt regression tests, ontology mapping assistance, Cypher generation evaluation, and security-focused checks for the open-source repository.

## Additional Context

The project was recently publicized after a full privacy and secret cleanup. The maintainer plans to use Codex to reduce review load and improve documentation, testing, release quality, and security checks as the project grows.
