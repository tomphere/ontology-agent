# Roadmap

This roadmap tracks near-term work for the open-source release.

## v0.1.x

- Add minimal demo ontology and mapping examples that use only synthetic data.
- Expand Docker deployment documentation for local and server environments.
- Add screenshots or short recordings for the dashboard, graph view, data workbench, and chat workflow.
- Improve API route test coverage for authentication, data source configuration, scene management, and graph queries.
- Add safer example defaults for self-hosted Langfuse and Neo4j deployments.

## v0.2.x

- Add a guided quickstart for ontology-to-Neo4j synchronization.
- Add prompt regression tests for natural-language Cypher generation.
- Add maintainer automation for release notes, dependency review, and issue triage.
- Add example plugin documentation for semantic search and custom agent tools.
- Improve observability docs for Langfuse tracing and graceful fallback behavior.

## Good First Issues

- Improve README screenshots and architecture diagrams.
- Add synthetic demo data and mapping samples.
- Add API examples for common graph queries.
- Improve frontend empty states and loading indicators.
- Add focused tests for configuration validation and secret masking.
